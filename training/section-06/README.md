# Section 6 研究与实验方案

当前交付：s6-r3，16页。配套PPTX、PDF、逐页PNG、讲师稿、国外课件具体页码、方案示例、公开数据和检查记录。

本节从公开研究的分组与测量讲起，说明变量、对照、区组、独立重复、盲法、参数组合、样本量依据和资源安排。以流程、层级、分支及原生数据图表达关系。没有课堂练习。

12页原生连接图，3页原生表格，1页原生折线图。图表自带嵌入工作簿；正文、图形与表格可编辑。底部来源与讲者备注保留原始材料定位。

公开数据取自UC Davis 2026年两水平因子设计课件第8—9页，属于教材教学示例。没有取得原始重复测量值，y的物理单位未注明，因此只复算条件增量，不绘误差条、不做显著性结论。本科课程研究方案属于教学模拟，未开展实验。详见“方案示例与材料状态.md”。

构建：使用Artifact Tool运行build.mjs；render.py将最终PPTX通过LibreOffice导出PDF，再由Poppler生成16页PNG。check_delivery.py核对结构、来源数据、图表缓存与工作簿。运行环境路径见脚本。validation.json保留最终器结果，checks.json保留内容文件检查结果。

这次视觉审查依据LibreOffice实际渲染；未在Microsoft PowerPoint中实机复核。审查范围和修改见“审查记录.md”。
