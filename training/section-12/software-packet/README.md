# 软件成果台账与登记材料：教学示例

本包演示内部成果整理。实际运行的统计脚本、外部论文参考和技术交底教学稿分别登记，不把它们合并计作本人的论文、专利或已登记软件成果。台账中的三条记录都明确说明状态与贡献；“未申请”不等于登记被拒绝，代码能运行也不等于权属已确认。

source保存短脚本、公开CSV和本轮实际输出。snapshot.json固定代码、数据与输出的字节哈希，来源提交用于追溯原课程代码，不代替权利证明。actual-console.json是本轮脚本标准输出，不是Agent界面截图。软件功能说明为课程编写的使用材料，未制作正式登记申请书或交存文件。

成果台账.csv与JSON内容一致，可以编辑。登记材料核对.json按官方办法区分申请表、程序与文档、相关证明，并列出实际缺口。所有“本人贡献”都须由实际人员与职责材料确认；本包没有代签、假身份证明、假登记号或假证书。正式报送结题时，还要回到项目和单位对成果范围的要求。

来源为国家版权局《计算机软件著作权登记办法》第四、七至十一、二十条。本轮只说明材料类别和案例状态，不演示登记系统操作，不提供未经核验的当期费用、办理期限或授权判断。原始链接和采用范围见参考资料.md。

检查程序check_software.py从CSV独立复算，并核对快照、纳入行、输出、台账和未登记状态。它不能证明作者贡献、权属或登记适格性。软件程序与文档较短，保留实际内容，不通过生成无用代码填满页数。

外部材料定位：论文保留公开DOI链接，Section 11技术交底教学稿保留已核对存在的固定Git提交链接；二者作为参考，不重复打包为本人的成果或登记证明。
