# 跨工具代码的资料与核对范围

2026年10月19日。原始数据来自palmerpenguins，CC0；来源与哈希见source.json。

- Python统计标准库：https://docs.python.org/3/library/statistics.html 。已读mean与样本stdev说明；本轮运行版本由python-output/run.json记录。
- R数据输入：https://stat.ethz.ch/R-manual/R-devel/library/utils/html/read.table.html 。已读read.csv、NA字符串和stringsAsFactors参数。
- R样本标准差：https://stat.ethz.ch/R-manual/R-devel/library/stats/html/sd.html 。已读n−1分母及缺失值规则。
- WebR官方使用说明：https://docs.r-wasm.org/webr/latest/downloading.html 与 https://docs.r-wasm.org/webr/latest/evaluating.html 。已读Node本地运行及evalR接口；执行固定npm版本0.6.0，没有使用latest开发版。具体R版本回实际sessionInfo核对。
- IBM MEANS：https://www.ibm.com/docs/en/spss-statistics/31.0.0?topic=reference-means 。官方搜索索引可读TABLES、BY及CELLS的COUNT、MEAN、STDDEV语法；完整页面本轮403。
- IBM GET DATA：31版Command Syntax Reference官方索引，https://www.ibm.com/docs/en/SSLVMB_31.0.0/pdf/IBM_SPSS_Statistics_Command_Syntax_Reference.pdf 。索引可读TXT、FIRSTCASE、DELIMITERS、QUALIFIER与VARIABLES；PDF本轮403，未声称已读取整本手册。
- IBM聚合函数：https://www.ibm.com/docs/en/spss-statistics/32.0.0?topic=aggregate-functions-command 。官方索引可读N、MEAN、SD用途；完整页面403。另读官方BREAK及SAVE TRANSLATE索引说明，不据此宣称31版全部语法已运行。
- Cursor官方概览：https://cursor.com/docs 。只用于说明代码编辑与实际执行需要分别核对，未在Cursor中操作，不引入模型排名或当前套餐比较。

三份源文件是课程编写的教学代码。Python和R有实际执行记录；SPSS为未执行代码，不用其他解释器冒充IBM SPSS。显示的mm结果为公开数据二次计算，没有生成新的科研观测。
