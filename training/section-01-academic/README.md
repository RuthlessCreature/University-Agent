# Section 1：科研 AI 的能力、原理与学术边界

12 页中文学术讲授课件。按用户反馈重写：本节不安排课堂练习、账户操作、阅读笔记任务或学员文件提交。

内容从科研流程与模型范围进入预训练、后训练、推理、上下文和检索，再讲能力、任务组织、提示设计、工具选择、推断边界与出版规范。国外课件参考与具体页面见 `国外课件参考.md`。

交付文件：

- `output/` 中的 PPTX，文字、表格、原理图和数据图均可编辑。
- `renders/` 中由最终 PPTX 经 LibreOffice 与 Poppler 导出的 PDF、逐页 PNG。
- `讲师稿.md` 与 `sources.json`，包含逐页讲法、限定与来源链接。
- `sources/citation-study.pdf`：真实公开研究原件；第 4 页表 3、4 是图表数据依据。
- `sources/citation-data.json`：报告值、分母与适用条件。
- `checks.json`、`validation.json`、`审查记录.md`：文件验证和人工查看记录。

文献幻觉图使用 Walters 与 Wilder（2023）的报告值，不是当前模型评测，也没有重新运行该研究。原理图是课程的概念框架，不能当作某 Agent 的实际运行截图。

制作使用 Artifact Tool。最终文件尚未在 Microsoft PowerPoint 中实测；预览来自 LibreOffice。后续 Section 2 展开 Agentic AI、Agent 与 Harness，Section 3 展开 Humanizer，Section 9 单独核对 Science 等目标期刊的具体要求。
