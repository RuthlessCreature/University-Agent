# 通用助手的具体选用案例

Section1第9页配套材料。用同一份公开论文和报告值表，展示三种入口下如何交代任务、需要哪些工具、拿到什么文件后才能检查。

讲师先打开论文第4页，解释两种分母，再打开共同任务与入口任务，最后对照人工核对示例。三条路线各有侧重，也有功能重叠；文件工具缺失、材料读不全或不能保留出处时，需要换入口或补充材料。不要把课程示例当作产品排名。

这些任务尚未在Claude、ChatGPT或DeepSeek上执行。本目录没有模型结果、运行截图、耗时和费用比较。人工核对示例是依据公开材料写成的课程文本。case.json保留三条executed:false及result_file:null，检查脚本不向模型或外部账户发送内容。

本地检查：用Python运行check_choice.py。检查输入哈希、原文定位、四个报告比例、任务与状态对应，不验证产品当前可用性或回答质量。
