# 论文、预印本与专利的同窗比较

本例围绕生成式AI辅导，固定2024年1月1日至2025年12月31日，逐项读取一份预印本版本、一件专利申请公开和一篇期刊论文。记录的是这三条材料的公开事件，既不是全领域检索量，也不是每项工作最早出现的时间。检索与读取日期为2026年10月19日。

records.json与材料比较.csv可编辑，保存日期类型、研究或申请标识、贡献、限制、原始链接及定位。专利另记2024-02-14申请日和2023-02-14更早临时申请日，公开日为2024-08-15，已查看原始33页PDF的首页。专利法律状态未核验；不据此作授权、侵权或自由实施判断。

预印本使用arXiv:2405.14713v1，其全文已经列出L@S2024会议及相关DOI。预印本是所读版本的身份，不表示该研究永远未发表。扩大检索时应把相关版本归并，不能把同一项工作作为多次独立研究。SSRN候选页本轮返回403，未列入这三条已读材料；ACM DOI访问失败，不另造其在线出版日期。

先按日期定位，再比较每份材料实际上回答什么。界面做得更快、自适应内容能够生成、学生撤去AI后能独立作答，是不同问题。三份材料可帮助拟定下一步要验证的条件，尚不能推出全领域增长速度、未来热点或首次创新。若需要定量趋势，仍需在固定数据库中运行完整检索、保存全量导出、按统一规则去重并处理公开滞后；本例没有执行这些步骤。

第10页原图来自Calo与MacLellan论文Figure1，按CC BY4.0标注原作者和来源，完整图片随包提供。它是作者的方法图，包含作者系统界面，不是本项目执行截图，也不是学习成效数据。中文解释、任务安排和拟议问题由AI编写，尚待教师审定。

check_case.py仅核对三条记录、日期范围、日期类型、相关版本字段与原图哈希，不联网、不判断科研主张或专利法律状态。来源定位见参考资料.md，获取原件的哈希见retrieval.json；原PDF和HTML缓存未随包复制。
