# Section 3 Humanizer 与各类科研产物的表达

18 页学术讲授课件。以修改对照、批注、流程与关系图说明科研表达，包含两张按原始报告值重绘的研究数据图和一页核对表。无课堂练习。

本节参考UCL 2026年学术写作课件，具体页面及参考范围见《国外课件参考》。中文案例是课程编写的教学模拟，原稿、预设材料、修订稿和理由另存；没有伪装模型执行截图或真实成果。

交付包括可编辑PPT、PDF、18张逐页预览、讲师稿、案例差异说明、来源、源数据与检查记录。`lesson.json` 是逐页内容源文件。`build.mjs` 使用 Artifact Tool；`render.py` 经 LibreOffice 和 Poppler 渲染最终PPT；`check_delivery.py` 核对结构、图表报告值、原生对象和明确限定词。

PPT尚未在Microsoft PowerPoint中实测，自动检查不代表所有学术含义已被程序验证。人工逐页查看记录见《审查记录》。后续全课程进度在 `training/curriculum/section-progress.json` 中登记。
