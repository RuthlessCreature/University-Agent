# 围绕公开材料的三个月传播安排

本包是具体教学案例，四份中文草稿已经写成，但没有对外发布。第1周解释结果，第1月末解释方法，第2月末说明限制与预设答疑，第3月末说明复核和更新。相对时点只用于讲授内容安排，没有设置日历、定时任务或自动发布。

plan.json和传播安排.csv可以编辑。materials.json区分公开原始资料、课程二次计算和未纳入的材料；四份Markdown草稿分别保留来源、教学属性与解释范围。R3的问题由课程预设，不是实际收集的反馈；R4没有冒称发生过对外更正。访问、下载、引用与采纳均为未测量，不能填写成已取得的成绩。

正式使用应由实际作者确认署名、贡献、材料版本和允许公开的范围。论文预印本、接受稿、出版版本及专利等材料分别核对；本例不转载第三方课件图、整篇论文或未公开研究。AI协助改写不能取消事实核对或适用的披露要求。

讲师可依次打开四份草稿，说明它们各自增加了什么信息；再回到原CSV和计算结果核对数字。没有为保持更新频率编造新发现。是否继续发布应根据实际问题、资料变化和可用精力判断，不保证带来引用或影响。

check_outreach.py从随包CSV独立复算纳入数、均值差和分箱，核对草稿哈希、公开材料分类、CSV/JSON一致与未发布状态。它不证明作者批准、传播效果或科研结论。

本包的未发布状态指尚未按计划发为正式传播内容；课程仓库保存的是可审阅的教学草稿，不计作计划已执行。
