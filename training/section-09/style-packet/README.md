人工逐句阅读英文稿，已核对对象、组别、方向、数值和限定；没有新增P值或机制主张。完整稿件的学名、伦理、贡献、数据声明与研究贡献等尚未按期刊逐项审查，本包不作可投稿承诺。本轮未提交期刊、未取得编辑或审稿人意见。
