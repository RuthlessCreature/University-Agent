# Section 11 专利挖掘与技术交底

12页，最终版本s11-r6。PPTX在output，PDF和逐页预览在renders/s11-r6。讲师稿、来源定位与检索范围随包保留。页面1至2说明任务和材料，3至5阅读真实公开专利并比较，6至10讲追问、结构、实施细节、效果和图文对应，11至12讲实际文件流程及公开前核对。

第3页为EPO公开文献EP4636367A1第17页图2的局部渲染，保留全部图示与原始标记；其余流程框图保持原生可编辑，第5页为原生特征比较表。课程方案、公开技术和实际运行分别标识，没有样机、效果数字、授权或侵权结论。

patent-packet含已编写的教学输入、自编Word模板、实际生成的Word、来源账本、问题表、检索记录、特征比较CSV与方案流程Mermaid。Word是有实施细节缺口的教学草稿，不是可直接申请的专利文件。公开文献检索未查全，当前法律状态与实施自由未分析。

run_demo.py调用runtime-snapshot执行器读取现成段落并填充模板，保留输入与文件哈希。此脚本无外部模型调用，也不完成专利性判断。本轮Codex的网页原文阅读与该文件脚本分开记录。重跑会更新Word时间信息、哈希和运行记录，交付快照用于对照。

build.mjs使用Artifact Tool生成可编辑PPT，render.py导出PDF和PNG。check_delivery.py核对材料对应、Word内容、源图、原生对象、页数与验证记录。程序检查不表示研究者签核或用户教学验收。

本轮第5页补足US权利要求15的部件接触冲击限定，第10页以EP权利要求1、3、4的选定引用关系讲解新增条件，并单独说明权11的引用范围。claim-reading.json与feature-comparison.csv记录定位和阅读边界，不作完整保护范围解释。

第7页流程、SVG、draw.io及Word附图读取同一flow.json，S1至S4与实施说明对应。Word现为3页，末页列出流程及步骤所需材料；图在Word中是PNG，编辑源另附。check_scheme.py核对原生连接端点、图源连接、Word嵌入字节及标记。独立交付包可在已配置依赖的环境运行check_delivery.py，读取随包导出记录；这些检查不包括新机器上的Office实机测试。
