# University Agent

高校科研 AI 一日培训的双端演示应用及中文课件项目。

- **本地**：Codex 读取 `University-Skills` 中的 SKILL.md 并执行脚本。
- **云端**：Cloudflare Worker + MiniMax-M3 的科研工作台。
- **课件**：`training/` 放中文 PPT、授课时刻表、案例、演示脚本。

仓库只放实现代码及演示素材；技能规范在 [University-Skills](https://github.com/RuthlessCreature/University-Skills)。

技术实现状态以仓库的 `docs/STATUS.md` 为准，不以营销文字或 PPT 截图视为真实部署。
